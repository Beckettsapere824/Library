# Agent & Vibe Coding Courses

Courses and materials on agent-driven software development.
面向 Agent 驱动软件开发的课程与材料。

Ordered by depth for building agentic systems (engineering agents → applied SE with agents → Chinese CS146S track).
按构建 Agentic 系统的深度排序（工程化 Agent → 应用 Agentic SE → 中文 CS146S 路线）。

---

## 1. [Stanford CS329Z — Engineering AI Agents](https://cs329z.stanford.edu/)

Stanford course on engineering agentic systems: from LLM pipelines to compound AI systems and autonomous agents (RAG, tools, loops, evaluation, DSPy, projects).
斯坦福课程：工程化 Agentic 系统，从 LLM 流水线到复合 AI 系统与自主 Agent（RAG、工具、循环、评测、DSPy、项目）。

**Value:** Primary academic syllabus for *designing and evaluating* agents, not only using coding agents.
**价值：** 侧重**设计与评测** Agent 的主课程大纲，而非仅使用编程 Agent。

---

## 2. [Harvard CS2680 — Modern AI Systems](https://cs2680.seas.harvard.edu/)

Harvard course following one agent from coding-agent use and agent design down through serving (batching, KV cache, quantization, speculative decoding).
哈佛课程：从编程 Agent 使用与 Agent 设计，一路下沉到推理服务栈（批处理、KV cache、量化、投机解码）。

**Value:** Rare full-stack path from agent loop to production inference systems.
**价值：** 少见的从 Agent 循环到生产推理系统的全栈路径。

---

## 3. [EECS 498 AASE materials](https://github.com/eecs498-aase/materials)

UMich Fall 2026 “Applied Agentic Software Engineering” lecture/lab slides, demos, and EGM (Elephant-Goldfish) skills for agent-mediated design.
密歇根大学 2026 秋「应用 Agentic 软件工程」讲义/实验、演示与 EGM（大象-金鱼）设计 Skills。

**Value:** Concrete agentic SE pedagogy and installable skills for design-before-code workflows.
**价值：** 具体的 Agentic SE 教学法，以及可安装的「先设计再编码」技能。

---

## 4. [CS146S_CN](https://github.com/Lucaswang81/CS146S_CN)

Chinese materials for Stanford-style CS146S / modern software developer (“vibe coding”): assignments, tools, long-term CN tutorial track (unofficial localization).
斯坦福风格 CS146S / 现代软件开发者（vibe coding）的中文材料：作业、工具、长期维护的中文教程线（非官方本地化）。

**Value:** Accessible CN entry to agent-assisted software factory practices.
**价值：** 进入 Agent 辅助「软件工厂」实践的中文友好入口。
