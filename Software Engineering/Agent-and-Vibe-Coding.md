# Agent & Vibe Coding Courses

Courses and materials on agent-driven software development.
面向 Agent 驱动软件开发的课程与材料。

---

## 1. [Stanford CS329Z — Engineering AI Agents](https://cs329z.stanford.edu/)

Stanford course on engineering agentic systems: LLM pipelines to compound AI systems and autonomous agents.
斯坦福课程：工程化 Agentic 系统。

**Value:** Primary academic syllabus for designing and evaluating agents.
**价值：** 设计与评测 Agent 的主课程大纲。

---

## 2. [Harvard CS2680 — Modern AI Systems](https://cs2680.seas.harvard.edu/)

From coding-agent use and agent design down through serving (batching, KV cache, quantization).
从编程 Agent 与 Agent 设计下沉到推理服务栈。

**Value:** Full-stack path from agent loop to production inference.
**价值：** 从 Agent 循环到生产推理的全栈路径。

---

## 3. [microsoft/ai-agents-for-beginners](https://github.com/microsoft/ai-agents-for-beginners)

18 lessons to get started building AI agents (Microsoft curriculum, notebooks).
18 课入门构建 AI Agent（微软课程 + Notebook）。

**Value:** Structured beginner path with corporate curriculum quality and free materials.
**价值：** 有结构的入门路径，教材质量与可及性都不错。

---

## 4. [EECS 498 AASE materials](https://github.com/eecs498-aase/materials)

UMich “Applied Agentic Software Engineering” lecture/lab slides and skills.
密歇根「应用 Agentic 软件工程」讲义/实验与 Skills。

**Value:** Concrete agentic SE pedagogy.
**价值：** 具体的 Agentic SE 教学法。

---

## 5. [CS146S_CN](https://github.com/Lucaswang81/CS146S_CN)

Chinese materials for Stanford-style modern software developer / vibe coding track.
斯坦福风格现代软件开发 / vibe coding 的中文材料。

**Value:** Accessible CN entry to agent-assisted software practice.
**价值：** Agent 辅助软件实践的中文友好入口。
