# ML Practice — From Scratch & Interactive Labs

Implementations and demos for understanding algorithms, not production finance models.
用于理解算法的实现与演示，非生产级金融模型。

---

## 1. [eriklindernoren/ML-From-Scratch](https://github.com/eriklindernoren/ML-From-Scratch)

Classic pure-Python / NumPy implementations of ML algorithms without heavy frameworks.
经典纯 Python / NumPy 机器学习算法实现，不依赖重型框架。

**Value:** Forces understanding of updates and loss surfaces before library one-liners.
**价值：** 在库一行调用之前，强迫理解更新与损失曲面。

---

## 2. [trekhleb/machine-learning-experiments](https://github.com/trekhleb/machine-learning-experiments)

Interactive experiments: training notebooks + in-browser demos (TF/Keras → TF.js).
交互式实验：训练 Notebook + 浏览器内演示（TF/Keras → TF.js）。

**Value:** See train and play side by side; great for intuition, not for quant production.
**价值：** 训练与玩耍并排可见；适合直觉，不适合量化生产。
