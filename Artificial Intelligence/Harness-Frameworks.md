# Harness Frameworks

Agent runtimes, coding agents, MCP toolkits, and harness learning.
Agent 运行时、编程 Agent、MCP 工具箱与 Harness 学习。

---

## 1. [openai/codex](https://github.com/openai/codex)

Lightweight coding agent that runs in the terminal (Rust); OpenAI’s open coding-agent line.
在终端运行的轻量编程 Agent（Rust）；OpenAI 开源编程 Agent 路线。

**Value:** Reference terminal coding-agent UX and architecture from a major lab.
**价值：** 大厂终端编程 Agent 的 UX 与架构参考。

---

## 2. [xai-org/grok-build](https://github.com/xai-org/grok-build)

SpaceXAI / xAI coding-agent harness and fullscreen TUI (Rust): edit, shell, search, long tasks; headless and ACP; skills/plugins/MCP/subagents.
SpaceXAI / xAI 编码 Agent Harness 与全屏 TUI（Rust）。

**Value:** Production-shaped coding agent reference; study the loop, not only the model.
**价值：** 量产形态编码 Agent 参考；研究循环本身。

---

## 3. [oraios/serena](https://github.com/oraios/serena)

MCP toolkit for coding agents: semantic retrieval and editing — “IDE capabilities” exposed to the agent.
面向编程 Agent 的 MCP 工具箱：语义检索与编辑——把 IDE 能力暴露给 Agent。

**Value:** Concrete MCP layer between models and real codebases.
**价值：** 模型与真实代码库之间的具体 MCP 层。

---

## 4. [yc-software/qm](https://github.com/yc-software/qm)

Y Combinator multiplayer agent harness for work (Slack + web); scoped memory and sandboxes; self-host.
YC 多人工作 Harness（Slack + Web）；隔离记忆与沙箱；自托管。

**Value:** Company-scale agent deployment patterns.
**价值：** 公司级 Agent 部署范式。

---

## 5. [walkinglabs/learn-harness-engineering](https://github.com/walkinglabs/learn-harness-engineering)

Beginner-oriented harness engineering tutorial (0 → 1).
面向初学者的 Harness 工程教程（0 → 1）。

**Value:** On-ramp before reading large industrial harness repos.
**价值：** 阅读大型工业 Harness 仓库前的入门坡道。

---

## 6. [milind-soni/OpenMausBot](https://github.com/milind-soni/OpenMausBot)

Open-source Grok-bot-style agent with a virtual machine the bot can use.
开源 Grok Bot 风格 Agent，带可供 Bot 使用的虚拟机。

**Value:** Agent + real computer/VM control pattern (evaluate security carefully).
**价值：** Agent + 真实电脑/VM 控制范式（务必自行评估安全）。

---

## 7. [google-research/harness2](https://github.com/google-research/harness2) · [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)

Research / industrial harness artifacts from Google Research and DeepSeek.
Google Research 与 DeepSeek 的研究/工业 Harness 产物。

**Value:** Lab viewpoints on evaluation, control, and constrained agent runs.
**价值：** 实验室对评测、控制与受约束 Agent 运行的视角。
