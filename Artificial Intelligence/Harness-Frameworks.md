# Harness Frameworks

Agent runtimes and multiplayer harnesses (execution loops, scopes, TUI/CLI).
Agent 运行时与多人 Harness（执行循环、作用域、TUI/CLI）。

---

## 1. [xai-org/grok-build](https://github.com/xai-org/grok-build)

SpaceXAI / xAI coding-agent harness and fullscreen TUI (Rust): edit, shell, search, long tasks; headless and ACP modes; skills/plugins/MCP/subagents.
SpaceXAI / xAI 编码 Agent Harness 与全屏 TUI（Rust）：编辑、Shell、搜索、长任务；支持无头与 ACP；Skills / 插件 / MCP / 子 Agent。

Open-sourced under Apache-2.0; can point at local inference via config.
Apache-2.0 开源；可通过配置指向本地推理。

**Value:** Production-shaped coding agent reference from a frontier lab; study the loop, not only the model.
**价值：** 前沿实验室量产形态的编码 Agent 参考；研究循环本身，而非只盯模型。

---

## 2. [yc-software/qm](https://github.com/yc-software/qm)

Y Combinator multiplayer agent harness for work (Slack + web): per-person and per-room scoped memory, files, keychain, sandbox; self-host on your cloud.
Y Combinator 面向工作的多人 Agent Harness（Slack + Web）：按人/按房间隔离记忆、文件、密钥与沙箱；自托管在自有云上。

Model-agnostic core (Pi / Claude Code style drivers).
模型无关核心（Pi / Claude Code 类驱动）。

**Value:** Company-scale agent deployment patterns, not single-user chat.
**价值：** 公司级 Agent 部署范式，而非单用户聊天。

---

## 3. [google-research/harness2](https://github.com/google-research/harness2)

Google Research harness line for structured agent evaluation and control.
Google Research 面向结构化 Agent 评测与控制的 harness 路线。

**Value:** Research-grade harness design from a major lab.
**价值：** 大厂研究级 harness 设计参考。

## 4. [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)

DeepSeek agent harness artifacts for running and constraining agent workflows.
DeepSeek 用于运行与约束 Agent 工作流的 harness 相关产物。

**Value:** Complementary industrial harness viewpoint from a model lab.
**价值：** 来自模型实验室的另一工业 harness 视角。
