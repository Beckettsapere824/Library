# Agentic Skills

High-signal skill packs agents actually load (UI craft, education, research reach).
Agent 会真正加载的高信号 Skill 包（界面工艺、教育、研究触达）。

---

## 1. [emilkowalski/skills](https://github.com/emilkowalski/skills)

Design-engineering skills (animation curves, duration, review tables, Apple-style motion) from the author of Sonner; widely used to stop “AI UI slop”.
设计工程类 Skill（动画曲线、时长、评审表、Apple 风格动效），来自 Sonner 作者；广泛用于抑制「AI 界面垃圾感」。

Install via `npx skills@latest add emilkowalski/skills`.
安装：`npx skills@latest add emilkowalski/skills`。

**Value:** Encodes taste rules agents lack by default; highest practical leverage for product UI agents.
**价值：** 把 Agent 默认缺乏的品味规则写死；产品 UI Agent 上实用杠杆最高。

---

## 2. [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail)

Agent skill / workflow tooling aimed at practical multi-step agent use.
面向实用多步 Agent 使用的 skill / 工作流工具。

**Value:** Operational patterns beyond one-shot prompts.
**价值：** 超出一次性提示词的操作范式。

---

## 3. [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)

Skill-style packaging of Karpathy-oriented learning and coding habits for agents.
面向 Agent 的 Karpathy 风格学习与编码习惯 Skill 化封装。

**Value:** Aligns agent behavior with high-quality CS teaching instincts.
**价值：** 让 Agent 行为贴近高质量 CS 教学直觉。

---

## 4. [Egonex-AI/Understand-Anything](https://github.com/Egonex-AI/Understand-Anything)

Skills oriented to deep comprehension of arbitrary material for agent research loops.
面向任意材料深度理解的 Skill，服务 Agent 研究循环。

**Value:** Research agents need “understand then act”, not only retrieve.
**价值：** 研究型 Agent 需要「先理解再行动」，而非只检索。

---

## 5. [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach)

Reach / distribution oriented agent skills for connecting tools and audiences.
面向触达与分发的 Agent Skill，连接工具与受众。

**Value:** Complements pure coding skills with go-to-market agent patterns.
**价值：** 用增长向 Agent 模式补充纯编码 Skill。

---

## 6. [DozenTwelve/Papermorph](https://github.com/DozenTwelve/Papermorph)

Claude Code skill that turns textbook PDFs into narrated, animated, interactive static web lessons (also picture-book / documentary modes).
Claude Code Skill：把教材 PDF 变成旁白 + 动画 + 可交互的静态网页课（亦有绘本 / 纪录片模式）。

Demo bookshelf: [papermorph.diamonddoge.org](https://papermorph.diamonddoge.org/).
演示书架：[papermorph.diamonddoge.org](https://papermorph.diamonddoge.org/)。

**Value:** Turns static knowledge into explorable teaching artifacts agents can ship.
**价值：** 把静态知识变成 Agent 可交付的可探索教学产物。
