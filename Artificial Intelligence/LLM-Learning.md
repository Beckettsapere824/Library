# LLM Learning & Inference

---

## 1. [dive-into-llms](https://github.com/Lordog/dive-into-llms)

Hands-on LLM tutorials (fine-tune, deploy, agents, alignment); free, CN-friendly.
动手学大模型（微调、部署、Agent、对齐等）；免费、中文友好。

**Value:** Structured path from basics to applied LLM engineering.
**价值：** 从基础到应用的结构化大模型工程路径。

---

## 2. [DeepInfer](https://github.com/deepseek-ai/DeepInfer)

DeepSeek high-performance large-scale inference framework (kernels, MoE parallel, speculative decoding).
DeepSeek 高性能大规模推理框架（算子、MoE 并行、投机解码）。

**Value:** Production inference reference from a frontier lab.
**价值：** 前沿实验室生产推理参考。

---

## 3. [bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book)

Open textbook *深入理解 AI Agent* with PDF and chapter code.
开源教材《深入理解 AI Agent》含 PDF 与按章代码。

**Value:** Agent design + engineering in one maintainable repo.
**价值：** Agent 设计与工程合一的可维护仓库。

---

## 4. [stanford-cs336/spring2025-lectures](https://github.com/stanford-cs336/spring2025-lectures)

Stanford CS336 lecture materials (modern LM systems track).
斯坦福 CS336 讲义（现代语言模型系统轨道）。

**Value:** Course depth after short LLM intros.
**价值：** 短课之后的课程级深度。
