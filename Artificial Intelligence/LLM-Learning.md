# LLM Learning & Inference

---

## 1. [dive-into-llms](https://github.com/Lordog/dive-into-llms)

Hands-on LLM programming tutorials (fine-tune, deploy, agents, alignment, etc.) expanded from SJTU course notes; free and practical.
动手学大模型编程实践教程（微调、部署、Agent、对齐等），由交大课程讲义拓展；免费实用。

**Value:** Structured Chinese-friendly path from basics to applied LLM engineering.
**价值：** 从基础到应用的结构化、中文友好大模型工程路径。

---

## 2. [DeepInfer](https://github.com/deepseek-ai/DeepInfer)

DeepSeek’s high-performance inference framework used in large-scale production (optimized kernels, MoE parallelism, speculative decoding); offline inference open-sourced for DeepSeek-V4.1-Flash-class models.
DeepSeek 大规模生产用的高性能推理框架（优化算子、MoE 并行、投机解码等）；面向 DeepSeek-V4.1-Flash 类模型开源离线推理。

**Value:** Production inference engineering reference from a frontier lab (hardware-demanding).
**价值：** 前沿实验室的生产推理工程参考（硬件要求高）。
