# Library

Curated knowledge base with **two cores**: **Quant Finance / Quant Trading** and **Software Engineering + AI Agents**. Other tracks (pure math, tools, personal research) will grow over time.
策展知识库，**双核心**：**量化金融 / 量化交易** 与 **软件工程 + AI Agent**。纯数学、工具、个人研究等轨道会陆续补充。

This README is the **entry catalog**. Browse here first; open folder notes for detail.
本 README 是**入口目录**。先在这里导航，再进入各文件夹笔记。

Not investment advice. Prefer primary sources. Notes use English + Chinese where listed.
非投资建议。优先一手来源。列表处说明采用英中对照。

## How to use / 怎么用

1. Pick a **core** or **support** track below.
2. Open the linked note (short: what it is, what for, why it matters).
3. Follow suggested order inside learning notes; skip what you already own.

1. 先选下面的**核心**或**辅助**轨道。  
2. 打开链接笔记（短：是什么、做什么、为什么重要）。  
3. 学习类笔记内有建议顺序；已会的跳过即可。
