# Coding Algorithms (DSA)

Data structures, algorithms, and interview-oriented problem solving. Starter set — expand later.
数据结构、算法与面试向刷题。起步集——后续再补。

---

## 1. Structured roadmaps / 结构化路线

### [NeetCode](https://neetcode.io/)

Curated problem lists (e.g. 150) with video explanations; free tier is enough to start.
精选题单（如 150）+ 视频讲解；免费档足够起步。

**Value:** Best-known free “what to solve in what order” for interviews.
**价值：** 面试「先刷什么」最知名的免费答案之一。

### [Striver A2Z DSA Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/)

Step-by-step topic sheet widely used for complete DSA coverage.
按主题推进的完整 DSA 表，使用面很广。

**Value:** No-gap topic sequence if you have months, not days.
**价值：** 有几个月而非几天时，少漏洞的主题序列。

### [labuladong/fucking-algorithm](https://github.com/labuladong/fucking-algorithm)

Framework-style articles: not only solutions, but patterns (two pointers, sliding window, trees…).
框架式文章：不只给题解，更给套路（双指针、滑动窗口、树……）。

**Value:** Trains recognition of patterns, not memorization of one problem.
**价值：** 练模式识别，而非背单题。

## 2. Theory courses / 理论课

### [Princeton Algorithms, Part I](https://www.coursera.org/learn/algorithms-part1) (Coursera; audit free)

Classic Sedgewick course: stacks, queues, sorting, searching, with real implementations.
Sedgewick 经典课：栈队列、排序查找，带实现。

**Value:** Academic clarity without paying for a certificate.
**价值：** 不要证书也能拿到学术级清晰度。

### [MIT 6.006 — Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/)

OCW lectures and problem sets for rigorous foundations.
OCW 讲座与习题，偏严格基础。

**Value:** When interviews are not enough and you want CS depth.
**价值：** 面试不够、还要 CS 深度时用。

### Abdul Bari (YouTube) — Algorithms

Clear free lectures on core algorithm ideas (why, not only code).
核心算法思想的清晰免费课（讲为什么，不只贴代码）。

**Value:** Fast repair for “I can code it but cannot explain it”.
**价值：** 快速补「会写不会讲」。

## 3. Practice hygiene / 练习习惯

- Prefer **patterns** (window, graph BFS/DFS, DP states) over random hard problems.  
- Time-box: explain complexity out loud before coding.  
- One language fluency beats three languages half-known.

- 优先**模式**，少无目的随机 Hard。  
- 限时：动笔前先口述复杂度。  
- 一门语言熟练好过三门半生不熟。
