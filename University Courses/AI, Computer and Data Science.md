# AI, Computer, and Data Science Courses

## Harvard CS50

**Official index:** [CS50 course catalog](https://cs50.harvard.edu/x/courses/)

CS50 is Harvard’s collection of computer-science courses and OpenCourseWare. **CS50x**, [CS50’s Introduction to Computer Science](https://cs50.harvard.edu/x/), is the flagship introductory course. It is designed for learners with or without prior programming experience and covers computational thinking, algorithms, data structures, and programming in C, Python, SQL, HTML, CSS, and JavaScript. The self-paced course culminates in a final project.

**Access and certificate costs — Checked 2026-10-20.** CS50 course materials are available free through OpenCourseWare. CS50 offers a free URL-based certificate after meeting course requirements; an optional verified edX certificate is paid. Harvard Online lists CS50x’s verified certificate at US$219, while audit learning is free with selected materials. Prices and enrollment options vary by course and may change; check the course’s current enrollment page before payment. See the [CS50x certificate policy](https://cs50.harvard.edu/x/certificate/), [CS50 FAQ](https://cs50.harvard.edu/x/2026/faqs/), and [Harvard Online CS50x page](https://harvardonline.harvard.edu/course/cs50-introduction-computer-science).

## CS50 courses relevant to AI, computer science, and data science

### Current offerings

- [**CS50’s Introduction to Computer Science (CS50x)**](https://cs50.harvard.edu/x/) — Foundational computer science and programming. Covers algorithms, data structures, memory, security, software engineering, and web programming in C, Python, SQL, HTML/CSS, and JavaScript.
- [**CS50’s Introduction to Artificial Intelligence with Python (CS50 AI)**](https://cs50.harvard.edu/ai/) — Search, classification, optimization, machine learning, large language models, and other AI topics through projects. Intended as a follow-on for learners with CS50x or substantial Python experience.
- [**CS50’s Introduction to Programming with Python (CS50P)**](https://cs50.harvard.edu/python/) — Python fundamentals, testing and debugging, exceptions, regular expressions, libraries, object-oriented programming, and files. Designed for beginners; can be taken before, during, or after CS50x.
- [**CS50’s Introduction to Databases with SQL (CS50 SQL)**](https://cs50.harvard.edu/sql/) — Relational data and SQL, including CRUD, modeling, constraints, normalization, joins, views, indexes, and connections to Python and Java. Introduces SQLite, PostgreSQL, and MySQL.
- [**CS50’s Introduction to Programming with R (CS50R)**](https://cs50.harvard.edu/r/) — R and RStudio for statistical computing and data science: data structures, filtering, functions, data wrangling, visualization, packages, and testing.
- [**CS50’s Web Programming with Python and JavaScript (CS50 Web)**](https://cs50.harvard.edu/web/) — Web application development with Python, JavaScript, SQL, Django, React, and Bootstrap; includes databases, scalability, security, APIs, and user experience.
- [**CS50’s Introduction to 2D Game Development (CS50 2D)**](https://cs50.harvard.edu/games/) — Lua and LÖVE 2D for graphics, animation, sound, collision detection, and game projects. Prior programming experience is helpful.
- [**CS50’s Introduction to Cybersecurity (CS50 Cybersecurity)**](https://cs50.harvard.edu/cybersecurity/) — A five-week introduction to securing accounts, data, systems, and software, for technical and non-technical learners.
- [**CS50’s Introduction to Programming with Scratch (CS50 Scratch)**](https://cs50.harvard.edu/scratch/) — A visual, block-based introduction using animations, games, art, and stories to teach functions, conditions, loops, variables, and other fundamentals.
- [**CS50’s Computer Science for Business (CS50 Business)**](https://cs50.harvard.edu/business/) — A top-down CS50x variant for managers, product managers, founders, and decision-makers. Covers cloud computing, networking, privacy, scalability, security, and web/mobile technology.
- [**CS50’s Computer Science for Lawyers (CS50 for Lawyers)**](https://cs50.harvard.edu/law/) — A technology course for lawyers and law students, combining case studies with Python and SQL. Covers algorithms, cloud computing, databases, networking, privacy, programming, scalability, and security.

### Archived courses still available online

- [**CS50’s Mobile App Development with React Native (CS50 Mobile / CS50M)**](https://cs50.harvard.edu/mobile/) — React Native, modern JavaScript, JSX, app architecture, and user-interface projects. The course was retired on 2020-06-30; its site is an archive.
- [**CS50’s Understanding Technology (CS50 Technology / CS50T)**](https://cs50.harvard.edu/technology/) — A non-programmer introduction to hardware, the internet, multimedia, security, programming, and web development. Retired on 2024-06-30; its site is an archive.

### Related high-school program

[**CS50 AP**](https://cs50.harvard.edu/ap/) is Harvard’s high-school program aligned with the College Board AP Computer Science Principles framework. It combines CS50x and CS50T material. Any AP credit depends on school and College Board requirements, not on completing a standard CS50 course.
